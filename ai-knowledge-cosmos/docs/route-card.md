# Route Card — 夜览馆

- source materials: 原创中文 0→1 课程与笔记；公开 AI 教育学仅作教学法灵感。
- route: Night Exhibition / playable graphic essay. 首页 = 一条可走的走廊。
- material/proposal transform: 课程序列 → 展厅；续写 → 可点亮的下一颗字；注意 → 可转动的射灯；知识结构 → 一层平面图。
- primary subject: 八课走廊本身。
- identity: 炭黑馆墙 + 单一电酸色 chartreuse + 超号中文。
- interaction freedoms: 横向步行（滚动映射）、点选展品、旋转字盘、转灯、减弱动效竖向叠厅。
- reject if: 青绿发光球体；纸杂志刊头；卡片网格；节点图知识图谱。
