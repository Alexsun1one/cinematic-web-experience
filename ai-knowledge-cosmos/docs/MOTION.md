# Motion notes — 夜览馆

方向没改。这一轮只修手感。

## 当时哪里不对

- **走廊发飘：** 跟随用 `0.2 + |diff| * 0.62`，快滑时 catchup 直接到 1，慢滑又橡胶筋。射灯/铭牌走 React state，比轨道晚一拍，交接处会跳。
- **钉住弹开：** dwell 是两段折线，整数边界一阶不连续，厅与厅交接会顿一下。
- **字盘廉价：** 抬起冲量 4.4，还带缩放；滚动会强行换字，把你点的那颗抢走。
- **射灯打架：** 整块展柜 `touch-none`，竖滑被吞；滚动进度在松手后继续拧 yaw，吸附还可能转个没完。
- **换页像特效：** 光缝 720ms 还会撑开 14vw，页面已经切完才扫过去。
- **点不准：** 向前箭头和侧栏圆点命中区偏小；字盘只点得中 0.7 的立方。

## 改了什么

- 走廊：smootherstep dwell（整数处导数为 0）；指数跟随 `1 - exp(-λΔt)`，快滑把 λ 略抬高，避免拖尾。轨道和射灯/铭牌都在 rAF 里写 transform/opacity CSS 变量，React 只更新当前厅和下标。
- 惯性跳厅 620ms，滚轮/触摸取消；方向键仍可用，上下键等同左右。
- 字盘：ω=28 临界阻尼，冲量 1.05，按下略沉；更大透明命中盒；点过之后滚动不再换字。
- 射灯：先看位移再决定是拖还是让页面竖滑；拖过一次由你接管 yaw；吸附限 42 帧。
- 换页：360ms 薄缝 + 一层 void 罩住新页，可打断；后退反向。点击链接触发，避免先闪内容。
- 焦点：酸色 1px / 2px；侧栏圆点用 28px 热区，环画在圆上。
- 性能：WebGL 仍 DPR≤1.5，离开视野或切走标签即 `demand`。不加 Lenis。

减弱动效：走廊仍是竖向叠厅，无跟随、无光缝、无惯性。构图在。
