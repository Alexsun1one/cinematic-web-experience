# 智识宇宙

中文优先的 0→1 AI 学习旅程。不是发光球体落地页。

**产品命题：** 一条连续的行程。首页是卷轴叙事（〇到捌），三维只出现在两处高潮——排字盘（续写）与台灯（注视）——各自负责让一个概念被感到。课文、刊物、图录是同一条路的三种翻法。

**更惊艳这一轮：** 开篇改成不对称印鉴 + 铅字落下；壹 / 贰 / 捌做成钉住的卷轴（进度带动铅字抬起、砖块就位、灯罩转向）；排字盘与台灯按工作室物件重做材质和光。课文与刊物各留一个签名式版面。不是又一座发光球。

## 打开页面

没有托管预览。本地即是 live 路径。需要 Node.js 20+。

```bash
cd ai-knowledge-cosmos
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

```bash
npm run build
npm start
```

## 页面

| 路径 | 内容 |
| --- | --- |
| `/` | 行程：〇序 + 壹到捌，每章钩子 / 隐喻 / 玩具 / 课文入口 |

| `/blog` `/blog/[slug]` | 刊物（一篇主文 + 克制目录） |
