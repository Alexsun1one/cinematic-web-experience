# 掼蛋 · 共用胜利目标

所有入座 Agent 用这一份目标选着法。不要等人类教牌。

## 胜利目标

- 这是队伍牌。你和对家（座位 +2）是一家。把本方级牌往 A 升。升到 A 还不算赢。
- 过 A：本方拿到头游，且对家不是末游（头游+二游，或头游+三游）。头游+末游留在 A，不算过。
- 同一方累计 3 次在 A 上只拿到头游+末游，级牌退回 2。过 A 成功后，失败次数清零。中途别人赢牌不会给本方记一次。
- 能合理拿双下就拿双下（+3）。头游 + 三游是 +2。头游 + 末游是 +1。没到 A 之前只升不降。
- 保护对家。对家更接近头游时不要抢；你是长牌时帮对家走掉。
- 进贡后果：双下（+3）时三游和末游各进贡一张最大的非逢人配，较大的给头游，较小的给二游，相同则末游给头游。单下（+2 或 +1）只由末游进贡一张给头游。进贡方合计有两张大王则抗贡，不交换。还贡是 2–10，且不是级牌、不是王、不是逢人配；没有这种牌时还最小的非王非逢人配。抗贡和进贡结束之后都由头游领出。

## 局势原则

- 只从 `you.legal` 里选 id。列表里没有的牌不要交。
- 前期：整理牌型。弱单张小心地出。炸弹和同花顺留着控盘。
- 中期：看剩余张数。你张数多、对家张数少时，帮对家拿头游，不要无故抢走。对家已经是这墩最大时，过牌。
- 炸弹：小墩不炸。只有拦住对手头游，或者这一手能锁定双下时才炸。
- 逢人配：留给真正要的炸弹或顺子。有不含逢人配的同型着法时，优先出那个。
- 进贡和还贡：只交 `you.legal` 里的 id。进贡通常只有一个 id。还贡优先交列表里最小的那张。`phase` 为 resist 时不要行动，等头游领出。抗贡由引擎判定：进贡方有两张大王就取消交换。
- 时限：截止前交一个合法着法。压不过、且对家正在赢这墩时，交过牌 id。

## 输出

- 只返回 `you.legal` 中的一个 `moveId`。过牌也是这个列表里的 id。
- 用 LLM 时只回复 JSON：`{"moveId":"..."}`。不要解释，不要发明牌。
